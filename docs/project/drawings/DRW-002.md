# DRW-002: b wheel/frame assembly

## Scope
- Drawing ID: `DRW-002`
- Source PDF: `docs/sources/Antikythera Mechanism Bronze Rev 8.1/b.pdf`
- Source PNG prefix: `b_page*.png`
- Expected sheets/pages: `1..10`
- Current SCAD sheets: `scad/assemblies/drw002_sheet1.scad` through `drw002_sheet10.scad`

## Drawing Description
`DRW-002` is the B-series wheel/frame drawing set centered on the large spoked main wheel, its coaxial gear stack, and the linked roller/frame hardware mounted to that assembly. Across sheets, it covers:
- overall assembly views
- parts-list and exploded layout
- mounting-hole alignment
- gear-clearance reference diagrams
- detailed component views for `b0..b18`

## Rough Gaps To Resolve (next pass)
- `b0` tooth geometry still needs a refinement pass: the current tooth silhouette is closer than the original placeholder, but the outer/inner tooth proportions still do not fully match the source drawing.
- `b1` still needs a hole-by-hole reconciliation pass against the source drawing; see `docs/project/parts/b1_main_wheel.md` for the current hole schedule and missing-hole checklist.
- `b1` tooth/rim detailing is deferred for now; keep the current smooth rim/bevel placeholder until a better source view is available to resolve the tooth profile correctly.
- `b7` still has a vertical-stack discrepancy in the current interpretation; the drawing’s height chain does not yet reconcile cleanly with the rebuilt feature stack, so final step heights may need revision when related parts/assemblies are modeled.
- `b7` includes one top-bored side hole currently modeled with an inferred `R1.0`; the drawing location is clear (`5.9` left of center, `3.6` deep) but the radius is not explicitly specified and may need correction later.
- Sheets 4 and 5 are currently drawing-primitives only; decide whether any of those reference circles should be derived from shared gear modules for stronger traceability.
- Sheet 2’s parts table still references `cp-f1`, `cp-f2`, and `cp-f6`, but only the B-series part geometry is instantiated on the sheet.
- Several B-part files still expose only high-level defaults in their module signatures; a future pass could document or normalize the underlying feature parameters more explicitly.
- Sheet 7 preserves an uncertainty note from the source around the `b6` fitted feature; that interpretation likely still needs validation against the source drawing.
