# Drawing Sheet Review Checklist

Each sheet has five automated checks and two manual checks.

**Automated checks** (run `scripts/check_all.sh`):
- **Compile** — part and assembly files compile without errors
- **Wired** — `use` statement exists in `main.scad`
- **Mode** — mode branch exists in `main.scad`
- **Parts CSV** — all parts have a row in `parts_list.csv` with `scad_file` populated
- **Drawings CSV** — sheet has a row in `drawing_index.csv`

**Manual checks** (visual review in OpenSCAD):
- **Visual** — geometry looks correct against source PNG
- **Notes** — freeform notes on known issues or deferred work

## Workflow: Per-Sheet Review Cycle

1. Open source PNG in image viewer
2. Open assembly in OpenSCAD (`main.scad`, set mode to sheet)
3. Compare geometry against PNG — note discrepancies
4. Fix any issues found
5. Run `bash scripts/check_all.sh` — must pass
6. Tick off all checklist items for the sheet
7. Commit: `fix(drwXXX-sY): <description of fix>`
